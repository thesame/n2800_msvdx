# Matched decoder firmware

`msvdx_fw_mfld_DE2.0.bin` is the unchanged matched DE2 image used in hardware
qualification (32,788 bytes, firmware version 0x496). Its hash is pinned in
provenance.json and MANIFEST.sha256. The installed kernel requests it as
`/lib/firmware/cedarview-test/msvdx_fw_mfld_DE2.0.bin`.
